# Calculator
Console based calculator where user can enter two numbers to be used in different operations.   
Created using C#/.NET 10  
Following Microsoft's tutorial: https://learn.microsoft.com/en-us/visualstudio/get-started/csharp/tutorial-console?view=vs-2022#prerequisites

## Given Requirements:
- Create functionality that will count the amount of times the calculator was used.
- Store a list with the latest calculations. And give the users the ability to delete that list.
- Allow the users to use the results in the list above to perform new calculations.
- Add extra calculations: Square root, Taking the Power, 10x, Trigonometry functions.

## Features
- Console based UI
- Different possible operations
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Square_root
  - X10
  - Taking_the_power
  - Trigonometry functions

- Tracker for how many times calculator was used

- Saves latest calculations to a list
  - User can delete the list
  - User can use old results as new operands
